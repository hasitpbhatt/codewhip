# Multi-turn conversations — committee plan

## The committee's verdict (4 chairs)

**Privacy chair:** `outcomes.jsonl` stores `prompt_hash`, never the raw prompt. A transcript file stores raw prompts, so persistence must be **opt-in only** (`--continue`/`--session` armed ⇒ banner + redact secrets at write time). Files live under `<cwd>/.codewhip/sessions/` which is already self-protected. Must verify `share.ts` bundles never sweep session files in.

**UX chair:** the memorable verb is `--continue` (matches "keep the conversation going"). Listing: `codewhip sessions`. Prefix resolution ≥4 chars, unique — copy the established `resolveCheckpointRun` pattern (checkpoints.ts:111–116) so `codewhip run "..." --continue 37b0` just works.

**Simplicity chair:** zero new deps. One new module `src/sessions.ts` (~90 lines), a small loop seam, CLI wiring. `LoopMsg` is pure JSON data (provider-port.ts:3–16) — no serialization work needed.

**Loop chair:** `agentLoop` seeds `messages` at loop.ts:259–262 and never returns the transcript. Add `history?: LoopMsg[]` in, final transcript out. Compaction (which never touches system/user) keeps single-call size bounded; the saved transcript is the post-compaction one — honest.

## Design decisions

1. **Store:** `<cwd>/.codewhip/sessions/<runId>.json` — one `{ v: 1, ts, runId, provider, model, messages }` object per session, rewritten (not appended) at end of each run. System message is **stripped on save** and rebuilt fresh on resume (subagent roster / plan banner change between runs).
2. **Flags:** `--continue [prefix]` — bare = most recent session, with prefix = that session. Implies persistence. New `codewhip sessions` list command.
3. **All exit paths save:** success, error, cancel — partial transcript kept, matching the loop's existing philosophy.
4. **REPL gets it free:** each REPL line continues the shared in-memory transcript; saved on `.exit`.
5. **Session-scoped approvals (`s` answer) stay per-invocation in v1** — noted as follow-up, no scope creep.
6. **Schema ruling:** `sessions.json` schema v1 recorded in `docs/moat/00-convergence.md` (one paragraph) — AGENTS.md requires a recorded ruling for new state schemas.

## Implementation order

**A. `src/sessions.ts` (new, ~90 lines)**
- `SessionRecord` type; `saveSession(cwd, rec)` (redacts secrets, mkdir 0o700 / file 0o600, never throws); `loadSession(cwd, prefix)` (returns error string on missing/ambiguous/corrupt); `listSessions(cwd)` (newest-mtime first); resolve ≥4-char unique prefix.

**B. Loop seam (`src/loop.ts`, ~10 lines)**
- `LoopArgs.history?: LoopMsg[]` — seed `messages = [{system}, ...(history ?? []), {user, prompt}]`.
- `LoopResult.messages: LoopMsg[]` — return final transcript on every exit path (success/error/cancel, alongside the existing `text`/`error` returns at loop.ts:773–789).

**C. CLI (`src/index.ts`, ~60 lines)**
- `parseRunArgs`: accept `--continue [prefix]` (fallthrough at :408 currently rejects it); add `continue?: boolean; continuePrefix?: string` to `RunOptions`.
- `cmdRun`: when armed → load session (clean `exit 1` + stub receipt on error), print banner `!! --continue armed: resuming <prefix> (N prior messages) — transcript saved on exit (raw prompts on disk)`, pass `history` (stored messages; strip system if present from old files), and after `agentLoop` returns save `{ messages: result.messages.slice(1), provider, model }` and print `session: <runId> (M messages) — continue: codewhip run "…" --continue <prefix8>`.
- `cmdSessions` + dispatch + help text: `prefix  ts  model  msgs  first-prompt-preview` (redacted, 60 chars).

**D. REPL (`src/index.ts`, ~15 lines)**
- `cmdRepl`: keep `history` across lines, feed `result.messages` back, save session file on `.exit`/`.quit` and Ctrl-C.

**E. Tests**
- `src/sessions.test.ts`: save/load round-trip, prefix resolve (short/ambiguous), newest-first listing, secret redaction, corrupt-file leniency, no session dir → clean empty list.
- `src/loop.test.ts`: history seeding order (system → history → user); `result.messages` present on success and on a forced-error path.
- One CLI test: `--continue` with unknown prefix exits 1 with help, no partial write. Share-bundle regression test: session files never included.

**F. Docs**
- `docs/moat/00-convergence.md`: one-paragraph schema ruling (sessions, v1, opt-in, redacted).
- `docs/roadmap.md`: build-order entry. Help text + README flag table.

## Definition of done
`npm run lint`, `typecheck`, `build`, full `npm test` green; receipts still print on session runs; no raw prompt ever written without an explicit `--continue`/`--session` arm (verified by test); cost receipts unchanged.

Estimate: ~180 lines of source, ~160 of tests. No new runtime dependencies.
